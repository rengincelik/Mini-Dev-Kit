About the Project

Mini Dev Kit is a collection of reusable tools and systems designed to accelerate game development workflows. Each tool is modular, well-documented, and ready to be integrated into any Unity project.

Built with best practices in mind, focusing on performance, maintainability, and ease of use for rapid prototyping and production pipelines.
