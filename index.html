About the Project

Mini Dev Kit is a collection of reusable tools and systems designed to accelerate game development workflows. Each tool is modular, well-documented, and ready to be integrated into any Unity project.

Built with best practices in mind, focusing on performance, maintainability, and ease of use for rapid prototyping and production pipelines.

GPU Instancing Methods

▼

Three progressive GPU instancing approaches for rendering massive object counts efficiently.

Sprite Database Animator

▼

A Unity system for code-driven sprite animations using SpriteLibrary and SpriteResolver components.

Screenshot / GIF Placeholder
  • Dynamic Animation: Plays sprite sequences by Category
  • Frame Rate Control: Adjustable animation speed
  • Custom Inspector: Quick test buttons for all categories
  • Simple API: SetCategory("Run") to start animations

2D Movement Framework

▼

Comprehensive Unity 2D movement system with modular input mapping, DOTween-based animations, and sprite database animations.

Screenshot / GIF Placeholder

Core Systems:

  • Player Movement: Modular input-to-movement bridge with camera-relative controls
  • Object Animation: ScriptableObject-based DOTween system with visual editor
  • State Machine: Extensible player and vehicle state management
  • Custom Editors: Property drawers for visual inspector configuration
  • Multiple Movement Types: Velocity, AddForce, MovePosition, Torque, Transform
